# Excalidraw sources

Hand-editable originals for the README diagrams. Open any `.excalidraw` file at
[excalidraw.com](https://excalidraw.com) (File → Open) or in the VS Code /
Obsidian Excalidraw plugins.

| File | README figure |
|---|---|
| `stack.excalidraw` | you → host → warden → worker |
| `setup.excalidraw` | clone → onboard → ask |
| `route.excalidraw` | rules, then credits-first |
| `credits.excalidraw` | 80 / 15 / 5 spend mix |

GitHub shows the hand-drawn JPEGs (`docs/assets/diagram-*.jpg`) plus the
vector SVGs. If you change a drawing, export over the matching SVG and keep
the cream / teal / coral palette (`#F7F1E8`, `#0B3D3A`, `#E07A5F`, `#7A9E7E`).
